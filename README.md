# Live Auction

Самостоятельная модель торгов для локального просмотра: один лот, два участника, сервер — источник правды. Это не код продакшена. В проде контур сидел за мультиаккаунтом и каналом сделки, здесь оставлен только контур торгов.

База, ключи и внешний бэкенд не нужны. Состояние живёт в памяти процесса и пропадает вместе с ним.

## Запуск

```bash
npm install && npm run dev
```

Откройте http://127.0.0.1:5173 . Клиент — Vite на порту 5173, сокет — на 8787. Страница ходит на `ws://127.0.0.1:5173/ws`, Vite проксирует этот путь на сервер.

Если 5173 уже занят: `WEB_PORT=5191 WS_PORT=8791 npm run dev` и открывайте http://127.0.0.1:5191.

Участник выбирается переключателем «Алексей / Марина» в шапке. Второе окно с другим значением — это второй человек.

## Сценарий на 30 секунд

1. Откройте два окна браузера рядом.
2. В первом оставьте «Алексей», во втором переключитесь на «Марина».
3. У Алексея нажмите «Поставить». Во втором окне без перезагрузки сменится лидер.
4. У Марины задайте потолок, например 20 000, и включите автоброкера. Перебейте её ставку из окна Алексея: ответ Марины придёт с сервера, даже если её окно ничего не нажимало.
5. В одном окне включите Offline в DevTools, затем верните сеть. Появится баннер «соединение потеряно, состояние восстановлено», лидер и таймер совпадут со вторым окном.

## Проверки

```bash
npm test
npm run test:e2e
```

Перед Playwright остановите `npm run dev`, если он уже занимает порты 5173 и 8787: тест поднимает оба процесса сам.

## Что на экране

Один лот «Демо-лот»: лидер, сумма, шаг 500 ₽, таймер от серверного времени. Поле ставки, автоброкер с потолком, лента, счётчики ставок и участников онлайн, статус соединения. Начальная цена 10 000 ₽, до конца 2 минуты с момента старта процесса. Ставка в последние 30 секунд отодвигает конец так, чтобы осталось 30 секунд.
